# MapleStory MiniPet 🐱

**冒险岛桌面悬浮宠物** —— 透明置顶的迷你伙伴，可以换装、说话、攻击展示，还能把冒险岛的地图挂在桌面上。

数据直接读取本地 WZ 客户端文件，**完全离线可用**。MIT 协议开源。

> **V0.1.0** — 首个对外发布版本（2026-10）：多桌宠 / 音乐播放 / 桌面行走 / 椅子坐骑 / 地图背景

## 📥 下载

到 [Releases](https://github.com/tzy502/mapleStoryMiniPet/releases) 下载对应平台压缩包（self-contained，**免装 .NET**）：

| 平台 | 包名 | 说明 |
|---|---|---|
| Windows 10/11 x64 | `MiniPet-<版本>-win-x64.zip` | 解压后运行 `MiniPet.exe` |
| macOS Apple Silicon | `MiniPet-<版本>-macos-arm64.zip` | 解压得 `MiniPet.app`，首次运行**右键 → 打开** |
| macOS Intel | `MiniPet-<版本>-macos-x64.zip` | 同上 |

发布包不含游戏数据——首次启动需在设置页配置你自己的冒险岛 WZ 客户端目录（见下方「首次配置」）。

## ✨ 功能简介

### 🐾 多桌宠（V0.1.3）
- 桌面可**同时存在多只桌宠**：可以是不同的纸娃娃，也可以是不同的怪物（Mob）/ NPC，任意混搭
- 每只桌宠**独立窗口位置 / 缩放 / 外观 / 动画**，拖到哪重启就回到哪
- **主宠唯一、可随时切换**：只有主宠挂地图背景、只有主宠响应 Agent 状态特效；旧版单宠配置启动自动迁移，原宠物、位置、缩放都不丢

### 🧍 纸娃娃（角色换装）
- 透明无边框置顶悬浮窗，鼠标左键拖拽移动
- 空闲随机动画：**站姿 + 攻击（武器展示）动作**随机切换（swingO/T/P、stab、shoot），播完回归站姿——对齐冒险岛 mob 行为
- 分层拼装：身体 / 发型 / 脸型 / 耳朵 + 皮肤（中文名）/ 帽子 / 披风 / 上衣 / **套服** / 裤子 / 鞋子 / 手套 / 武器 / 盾牌 / **面饰(101) / 眼饰(102) / 耳环(103) 三槽可同穿** / 坐骑 / 椅子
- 装备特效：`Effect/ItemEff.img` 全局特效表（冰凌披风、神之子头冠等 18 帧循环动画）
- 发型 17337 个全量加载，中文名检索（性别不限）
- 染发调色（HSV 色相/饱和度/亮度）、预设管理（新建/保存/覆盖/加载/重命名/复制）

### 💬 聊天气泡
- 角色头顶随机冒泡（9-slice 样式），淡入淡出
- 纸娃娃 / 怪物 / NPC 三种锚定规则，长文本自适应

### 🗺️ 地图背景（两种模式）
- **静态地图**：整张地图作为桌面背景（裁紧透明边距、落地对齐、点击穿透）
- **摄像机模式**：拖动 / 缩放（0.25~4 倍）地图窗口，背景自动视差滚动
- 区域树选择器（世界 → 区域 → 地图）、图层开关、裁切设置

### 🧰 素材浏览
- 怪物 / NPC / 纸娃娃部件全量浏览（分类树：👾 素材组 + 🧍 纸娃娃组）
- 中文名检索、分页跳转、穿身上实时预览、应用到主窗口

## 🚀 快速开始

### 环境要求
- 使用发布包：无需安装任何运行时
- 从源码构建：.NET 9 SDK
- 冒险岛客户端 WZ 数据目录（`Character.wz` / `Mob.wz` / `Map.wz` 等拆包文件，**发布包不含游戏数据**）

### 编译运行

```bash
# 编译（macOS 构建加 -p:UsedAvaloniaProducts= 跳过遥测分析）
dotnet build MiniPet/MiniPet.csproj -c Debug -p:UsedAvaloniaProducts=

# 运行（macOS 桌面需保持显示器唤醒：caffeinate -dimsu）
dotnet run --project MiniPet/MiniPet.csproj
```

### 首次配置

1. 启动后右键桌宠 → 设置中心（**未配置 WZ 时启动自动打开设置页引导**）
2. 配置 **WZ 库路径**（`WzComparerR2.WzLib.dll`）
3. 配置 **WZ 数据路径**（客户端 Base/Data 目录，含 `Base.wz` / `Character.wz` / `Map.wz` 等）
4. 保存后自动加载，开始使用

地图缓存到本地（macOS `~/Library/Caches/MiniPet`，Windows `%LOCALAPPDATA%\MiniPet\cache`），二次加载秒开。

### 发布包说明

- **配置与日志与程序同目录**（`settings.json` / `wz-config.json` / `MiniPet.log`）——整个文件夹拷走即带走配置
- 桌宠不进任务栏（Windows）；macOS Dock 默认显示图标（桌宠右键菜单「🚢 Dock 图标」可切回隐藏）；托盘（状态栏）Slime 图标常驻
- Windows：解压后运行 `MiniPet.exe`（SmartScreen 提示「仍要运行」即可）
- macOS：解压得 `MiniPet.app`，首次运行**右键 → 打开**
- 首次启动未配置 WZ 自动打开设置页引导

## 💡 操作提示

- **左键拖拽**：移动桌宠
- **右键**：打开菜单（切换动画 / 人物 / 背景模式 / 气泡 / DSH / 设置）
- 地图摄像机模式：左键拖相机、滚轮缩放、右键拖窗口位置

### 🐾 多桌宠

- **加第二只**：右键任意桌宠 → **🐾 桌宠 → ➕ 添加桌宠**，新桌宠会先复制当前这只（外观、缩放），再自己换成想要的纸娃娃 / 怪物 / NPC；设置中心 **🐾 桌宠** 页也能添加
- **设为主宠**：右键目标桌宠 → **🐾 桌宠 → ⭐ 设为主宠**（设置中心 **🐾 桌宠** 页同样可以）；主宠全局只有一只，切换后旧主宠的地图背景会收起
- **移除**：右键目标桌宠 → **🐾 桌宠 → 🗑 移除这只桌宠**（或设置中心 **🐾 桌宠** 页）；**最后一只桌宠不可移除**，主宠被移除时第一只剩余桌宠自动继任
- **主宠特权**：只有主宠挂地图背景（静态图 / 摄像机窗口），也只有主宠响应 Agent 状态特效（干活 / 完成 / 出错）；其余桌宠保持自己的随机动画与随机气泡
- 每只桌宠的**窗口位置、缩放、外观各自独立**保存，拖完重启回到原位；右键菜单里背景相关项对非主宠不可用
