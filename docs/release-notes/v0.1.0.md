# MiniPet V0.1.0

## 下载

| 平台 | 包 | 运行 |
|---|---|---|
| Windows 10/11 x64 | `MiniPet-0.1.0-win-x64.zip` | 解压运行 `MiniPet.exe`（SmartScreen 选「仍要运行」） |
| macOS Apple Silicon | `MiniPet-0.1.0-macos-arm64.zip` | 解压得 `MiniPet.app`，首次右键 → 打开 |
| macOS Intel | `MiniPet-0.1.0-macos-x64.zip` | 同上 |

免装 .NET。

## 首次配置

程序不含游戏数据。首次启动自动打开设置页：配置 **WZ 数据路径**（冒险岛客户端 Base/Data 目录）→ 保存自动加载。日志在程序目录 `MiniPet.log`。
