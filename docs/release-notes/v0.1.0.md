# V0.1.0 发布说明（2026-10）

首个对外发布版本。全部官方发布包为**纯净版（NO_AI 编译）**：不含任何 AI 功能、无网络连接、无文件监控，也不包含任何游戏数据。

## 下载

| 平台 | 包 | 运行方式 |
|---|---|---|
| Windows 10/11 x64 | `MiniPet-0.1.0-win-x64.zip` | 解压运行 `MiniPet.exe`（SmartScreen 提示时选「仍要运行」） |
| macOS Apple Silicon | `MiniPet-0.1.0-macos-arm64.zip` | 解压得 `MiniPet.app`，首次运行**右键 → 打开** |
| macOS Intel | `MiniPet-0.1.0-macos-x64.zip` | 同上 |

self-contained 发布，目标机免装 .NET。

## 主要功能

- **多桌宠**：桌面同时养多只（纸娃娃 / 怪物 / NPC 混搭），位置缩放各自独立；主宠唯一可切换
- **纸娃娃换装**：身体 / 发型（17337 个，中文名检索）/ 脸型 / 帽子 / 套服 / 武器等全槽位 + 染发调色 + 装备特效
- **桌宠行走**：地图 Foothold 物理行走的「无限之路」背景模式，宠物在地图上自主巡游
- **音乐播放**：WZ BGM 目录浏览 / 播放 / 迷你控制条 / 曲目联动地图
- **地图背景**：静态整图与摄像机（拖动 + 缩放 + 视差）两种模式
- **聊天气泡 / 椅子 / 坐骑 / 表情** 等
- **托盘（状态栏）图标**：Slime 图标常驻，显示/隐藏/居中/音乐快捷操作/退出

## 首次配置（必须）

程序**不含游戏数据**，首次启动自动打开设置页：

1. 配置 **WZ 库路径**（`WzComparerR2.WzLib.dll`，发布包已带）
2. 配置 **WZ 数据路径**（冒险岛客户端 Base/Data 目录，含 `Base.wz` / `Character.wz` / `Map.wz` 等）
3. 保存后自动加载

## 已知事项

- macOS 包为 ad-hoc 签名（无开发者证书）：首次运行需**右键 → 打开**放行一次
- Windows Defender SmartScreen 会提示未知发布者，选「仍要运行」
- 发布包无控制台，日志在程序目录 `MiniPet.log`
- 需要 Agent 观察（DSH / Hermes / Claude Code / Codex 状态反映）的开发版请从源码自行构建（默认构建即含；纯净版加 `-p:MiniPetNoAi=true`）
- 游戏素材版权归 Nexon 所有，本项目仅用于学习研究
