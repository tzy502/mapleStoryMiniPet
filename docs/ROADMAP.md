## 双线开发规划（2026-08 起）

### V0.1.1 — 维护线（master 分支）

**定位**：小版本维护，不引入新功能面。在 master 分支上持续维护。

**范围**：
1. **Bug 修复**：收集并修复 V0.1.0 遗留 bug（以用户反馈 + 已知问题清单为准，见 `docs/ai/BUGREPORT-*.md`）
2. **AI 模块关联迭代**：Hermes 集成相关的小步迭代（现有 WS/REST/SQLite 适配链路、7 态动画映射、设置页 AI 区），跟随 master 发布

**约束**：
- 只改 bug，不扩功能范围
- 每个修复走「黑盒复现 → 根因 → 修复 → 回归」流程（Agent 禁止直接写代码，交由 Claude Code）

### V0.2.0 — 功能线（独立分支 feat/v0.2.0-music）

**定位**：下一个功能版本。**独立分支开发**，与 master 维护线隔离。

**范围**：
1. **音乐模块（复刻 WZ）**：解析并播放 WZ 客户端内的音乐资源（BGM/音效），数据一切从 WZ 走（沿用项目铁律：禁数据库、禁硬编码路径）
2. **UI 维护**：现有 UI 的维护性工作（布局、交互、样式一致性）
3. **新 UI 迭代**：基于维护后的 UI 做新迭代（具体条目在需求分析阶段逐条确认）

**流程**：严格瀑布 —— 需求分析（逐条确认，需求编号 F15+ 追加到 `docs/ai/requirements-analysis.md`「新增需求 v1.x」章节）→ 软件设计（`docs/software-design.md` 追加章节）→ 开发（Claude Code）
