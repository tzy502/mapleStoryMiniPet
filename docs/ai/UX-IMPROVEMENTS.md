## 五、纸娃娃配置差距对照（MapleSalon2，2026-08-16 补充）

> 用户点名：MapleSalon2 "发型先整合再调整颜色"——对照我们缺什么。

### 发型/染发体系（重点差距）

| MapleSalon2 能力 | 实现方式 | MiniPet 现状 | 差距 |
|---|---|---|---|
| **发色预设体系** | `const/hair.ts` 8 色表（HairColorHex：黑/红/橙/黄/绿/蓝/紫/棕）+ **发型 id 第 3 位编码发色**（getHairColorId = id[2]） | ❌ 无发色概念，只有 HSV 整体调 | **缺发色维度** |
| **发色整合色板** | HairDyeTab → AllColorTable：选中发型后展示**该发型全部可用发色缩略图**（同款型不同色一次看全） | ❌ 无色板；发型按**显示名**折叠分组，组内是 HSV 滑块 | **缺"先整合发色再调色"的主流程** |
| **混合染发 MixDye** | `dyeInfo={color, alpha}`：**原发色 + 目标发色按 alpha 比例混合**（MixDyeTable） | ❌ 无 | **缺混合染发** |
| **HSV 染发** | EquipItemHSVInfo（H/S/V 三值，色相环/饱和度/明度渐变） | ✅ 有（组内 HSV 滑块 + 设置页染发滑块） | 已覆盖 |
| **独立染发 tab** | DyeTab（HairDyeTab / FaceDyeTab / MixDyeTable / 导出） | 🟡 染发内联在纸娃娃设置页 | 可升级为独立面板 |
| **换色即换 id** | changeHairColorId(id, colorId)：发色=id 变体，**换色=切 id**（无需合成） | 🟡 染发走逐像素 HSV 合成（性能差） | 数据层差异 |

### 其他纸娃娃配置差距

| MapleSalon2 | MiniPet | 说明 |
|---|---|---|
| 当前穿戴列表可交互（每项 HSV/删除/编辑，CurrentEquipmentDrawer） | 🟡 只读摘要 14 行 | 可升级 |
| 收藏独立面板（Favorite drawer） | 🟡 收藏按钮+列表 | 可独立管理 |
| 性别显示开关（GenderSelect: showItemGender） | ❌ 无 | 素材库按性别过滤已有，但无"显示性别标记"开关 |
| 仅现金 / 仅可染筛选（OnlyShowCashSwitch/DyeableSwitch） | ❌ 无 | 可后置 |
| 渲染模式切换（CharacterRenderingSwitch：icon/character） | ❌ 无 | 预览模式切换 |
| 穿戴项内嵌染发信息（EquipItem 里 HSVInfo/MixDyeInfo 徽标） | ❌ 无 | 穿戴列表显示染发状态 |
| 皮肤分类选择（openSkinSelection） | ✅ 皮肤下拉 | 已覆盖 |
| 坐骑/椅子独立分类（Mount/Chair drawer） | 🟡 设置行选择 | 已覆盖基础 |

### 建议实施顺序（发色体系，用户点名）
1. **P0 发色数据层**：发型 id 第 3 位提取发色（8 色表）——对齐 MapleSalon2 getHairColorId/changeHairColorId；发色名/色值表（const 常量）
2. **P1 色板整合**：发型列表选中后显示**该发型全部发色缩略图色板**（同款不同色一次看全，点色块即换 id 变体）——替代/补充当前"按显示名折叠"（折叠仍保留，组内展示色板而非仅 HSV）
3. **P2 MixDye 混合染发**：dyeInfo（color+alpha）选择器（原色+目标色混合比例）——数据模型加 MixDye 字段（ItemInfo 扩展）
4. **P3 性能**：换色走"切 id 变体"（WZ 自带该色）而非逐像素 HSV 合成；HSV 仅作微调兜底

> 注：P0/P1 的数据基础（id 编码发色）是冒险岛 WZ 标准结构，桌宠 WZ 同源可用；实施前先用自检 probe 验证发型 id 分布（如 30000/31000/32000… 的第三位）。
