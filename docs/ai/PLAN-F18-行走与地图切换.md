# F18 行走与地图切换 · 算法设计（胶水 2026-09-14 口述整理）

> 状态：待确认（三个默认值见 §7）｜ 落地位置：`MiniPet/Services/`（模式3 行走模式）
> 本文把胶水的口述规则整理成可实现的状态机；实现前先对齐一遍口径。

## 1. 触发与生命周期

| 事件 | 行为 |
|---|---|
| 开始播放音乐 | 进入行走模式：按 §2 选图 → 按 §3 选方向 → 人物开始行走 |
| 歌曲播放完 | 人物**立即停止**，淡入淡出切到**下一张地图**（下一首对应地图），然后继续走 |
| 停止播放（Stop，不含暂停） | 退出行走模式 |
| 暂停 | 人物暂停（保持不动） |

**多宠**：先默认**只有主宠**参与行走，其他桌宠**全部隐藏**。

## 2. 选图（沿用已实现的链路）

1. 当前曲目 → `MusicCatalogService.GetFirstMapByReturnMap(trackKey)`（实时算：该 BGM 全部相关地图的 `info/returnMap` 众数，不查表）；
2. 返回 null → 回退链（沿用上一首地图 / 默认城镇）；
3. `Bgm00/Silence` 已被硬编码忽略，不参与。

## 3. 方向选择：**模拟行走，取更长的一边**

从**入口传送门**吸附到的 foothold 段出发，沿 foothold 图（`prev`/`next` 链 + 绳/梯 + 跳跃 ≤77px + 下落）分别模拟走到两端，得到两个方向的路径：

- **向下方向**：路径净位移沿 **+y**（世界坐标 y 向下为正）
- **向右方向**：路径净位移沿 **+x**

取**累计长度更长**的那个方向作为行走方向（同长取向右）。

> 待确认 ①：这里的"长度"是**路径累计长度**（含跳跃/爬绳），还是**净位移**？本文默认按**累计长度**。

## 4. 行走（物理参数照 sdlMS）

| 量 | 值 | 来源 |
|---|---|---|
| 水平速度上限 | ±125 px/s | `character_logic_system.h` |
| 水平加速度 | ±1400 px/s² | 同上 |
| 地面摩擦 | 800 | `physic::walk` 实参 |
| 重力 | 2000 px/s² | `run_fall` |
| 起跳初速 | −555 px/s | `vspeed_min × 0.1` |
| 下落终速 | +670 px/s | `vspeed_max` |
| 贴地 | `pos.y = k·x + intercept`（段内直线） | `physic::walk` |

行走中若越过段边界 → 用 `prev`/`next` 切段；切不过去且禁止掉落 → 贴边停住。

## 5. 走到传送门 → 淡入淡出切换地图

**候选传送门**（从当前位置沿行走方向遇到的下一个）：

1. 不是本次的**入口传送门**；
2. `tm`（目标地图）非空且 ≠ `999999999` / `-1`；
3. **目标地图的 `info/bgm` == 当前播放曲目**（即"下个地图还得是这首 BGM"）。

满足 → 走到该传送门 → **淡入淡出**（旧图淡出、新图淡入）→ 新地图里重新按 §2/§3 选方向继续走。

## 6. 没有可传送的传送门 → 半程折返

**"没有"的定义**（胶水原文）：

- 全图**只有一个**传送门；**或**
- 除入口传送门外，**唯一的**那个传送门的目标地图 bgm 与当前 bgm **不一致**。

此时：

1. 沿当前 foothold **走到尽头**；
2. 走到**全程一半**时 → **回归初始位置**；
3. 然后从起点**往反方向**走。

> 待确认 ②：「走到尽头的一半就回归初始」＝走到一半**立即瞬移回起点**再反向走（默认），还是**掉头走回去**（等于往返）？

## 7. 待确认的默认值

| # | 项 | 本文默认 | 备选 |
|---|---|---|---|

| ② | 半程折返方式 | 走到一半**瞬移回起点**再反向 | 掉头走回起点 |

| ④ | 行走速度 | sdlMS 上限 **125 px/s**（含加速/摩擦） | 固定匀速 60/100 px/s |
| ⑤ | 宠物显示 | 仅主宠，其余 `Hide()` | 全部显示只移动主宠 |

## 8. 实现骨架（待确认后落地）

```
WalkModeService            // 状态机：Idle → Walking → Crossing(淡入淡出) → Walking … → Idle
├─ MapWalker               // 单张地图内的行走：链上移动 + 切段 + 跳跃 + 爬绳（sdlMS 物理）
├─ DirectionPicker         // §3 模拟行走选方向（复用 MapWalker 干跑，不出图）
├─ PortalChooser           // §5 候选传送门筛选（tm + 目标地图 bgm 比对，走已建的反向索引）
└─ MapTransition           // 淡入淡出（窗口 opacity 动画；0.5s）
```

- 复用：`MusicCatalogService.GetFirstMapByReturnMap` / `MapService.LoadMap`（foothold/tile/obj/life）/ `PaperdollService`（人物帧 walk1/walk2/ladder/rope）/ `AnimService`（动画驱动）；
- 新增：`ladderRope` 解析（项目当前没有，需按 `Map/…/ladderRope/{i}` 的 x/y1/y2/l 读，探针已验证字段）；
- 多宠：`PetWindow` 里非主宠窗口 `Hide()`。
