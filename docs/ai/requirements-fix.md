## 一、需要添加到需求文档的遗漏项

### 错误处理

| 编号 | 需求 | 说明 |
|------|------|------|
| E1 | WZ 加载失败 | wzlib DLL 找不到 → 提示配置路径；WZ 文件损坏 → 提示检查文件 |
| E2 | 资源缺失 | 某动作精灵图不存在 → 用 stand 代替；所有 sprite 缺失 → 显示占位图 |
| E3 | 配置错误 | wzlib 路径无效 → 按钮灰显、弹窗提示；BaseWZ 路径无效 → 同 |
| E4 | 网络异常 | Hermes 连接断开 → 自动重连（指数退避），状态栏红点提示 |
| E5 | 磁盘空间不足 | 缓存写入失败 → 跳过缓存，内存兜底 |

### 边界条件

| 编号 | 需求 | 说明 |
|------|------|------|
| B1 | 拖拽边界 | 宠物不可拖出屏幕边缘 >=50px |
| B2 | 多开策略 | 单实例互斥，第二次启动激活已有窗口 |
| B3 | 窗口缩放 | 固定尺寸 312×355，不拖拽缩放。地图模式下地图尺寸不变 |
| B4 | 首次启动 | 无 WZ 配置 → 弹出配置引导弹窗，配置完成后加载默认宠物 |
| B5 | 状态恢复 | 退出时保存当前角色、位置、设置 → 下次启动恢复 |
| B6 | 多显示器切换 | 断连时宠物迁移到剩余显示器，新接入时保持原位不动 |

### 非功能需求补充

| 编号 | 需求 | 说明 |
|------|------|------|
| NF9 | 日志 | 运行日志写入文件，INFO/WARN/ERROR 三级，日志轮转保留 7 天 |
| NF10 | 配置迁移 | 版本升级时旧配置文件自动兼容，新字段填默认值 |

## 二、需求文档中已有、精确化描述

### F5 动画行为（精确化）

| 触发 | 原描述 | 精确化 |
|------|--------|--------|
| 空闲太久 | 除 stand 外任意 | 空闲 15~30 秒（随机）后触发，可配置。有鼠标移动或键盘输入时重置计时 |
| 拖拽 | fly（拖拽中） | 拖拽开始时切到 fly，拖拽中循环播放，释放后立即切回 stand，无过渡 |  
| 退出 | die（单次） | 退出时若有 die → 播完退出；无则直接退出 |

### F4 气泡（补充内容来源）

气泡文本来源（P0 仅定义形式，内容归 P2）：
- P0 阶段：右键 → 测试气泡，显示预设测试文本
- P2 阶段：Hermes AI 自动生成，偶尔随机闲话

### F9 右键菜单（补充禁用态）

| 条件 | 行为 |
|------|------|
| 未配置 Hermes | "Hermes 终端" 灰显 |
| 未加载 WZ | "切换人物""切换背景""切换气泡""切换椅子/骑宠" 全部灰显 |
| 当前非 PLAYER | "切换椅子/骑宠" 灰显 |

## 三、验收标准补充

| 新增验收项 | 内容 |
|-----------|------|
| 首次启动 | 无 WZ 配置 → 弹出配置引导；无默认宠物 → 提示先配置 |
| WZ 错误 | DLL 找不到 → 弹窗提示路径无效；WZ 文件损坏 → 弹窗提示 |
| 资源缺失 | 某动作不存在 → 自动用 stand；全部缺失 → 显示占位标识 |
| 状态恢复 | 退出→重启→角色/位置/设置不变 |
| 拖拽边界 | 拖到屏幕边 ≥50px 自动归边，不出屏 |
| 空列表 | 右键菜单各子列表为空时显示"(空)"而非崩溃 |
| Hermes 连接 | 连接断开 → 3 秒内重连尝试，失败后指数退避 |
