# MiniPet 全系统体检报告（通俗版）

_体检日期：2026-08-15 · 体检方式：4 路并行代码审查 + 纸娃娃渲染专项_
_这份是给你看的版本：只讲"哪里会出问题、什么时候发生、影响什么"，不涉及代码细节。_

## 先说结论

项目整体**能跑、功能完整**，但存在 **3 个会直接坏事的严重问题**、约 **30 个中等问题**和一批小问题。最需要优先处理的：

1. **角色动画切换有个判断写反了**——角色在做"一次性动作"（比如挥剑）时，你让它走/飞，指令会被悄悄丢掉
2. **桌宠藏进托盘后还在全速运行**——每秒 30 帧渲染 + 随机冒泡全不停，白白烧 CPU，还会出现"幽灵气泡"
3. **每弹一个气泡就漏一块内存**——气泡弹得越多内存涨得越多，跑几个小时会明显变卡

## 一、纸娃娃（角色拼装）——你最关心的部分

| 问题 | 什么时候发生 | 影响 |
|---|---|---|
| **坐骑/椅子配了不生效** | 在设置里给角色配了坐骑或椅子，点应用 | 桌宠上完全看不到——设置项是摆设 |
| **帽子不遮头发** | 戴帽子时 | 帽子叠在头发前面/后面关系不对，穿帮（**已按参考项目 MapleSalon2 重写遮挡逻辑，正在验证**） |
| **角色可能整个消失** | WZ 数据不完整时 | 如果角色身体部件的数据缺了关键锚点，整个角色渲染不出来，且没有任何提示——界面上静默空白 |
| **切换动作第一次会卡** | 每次换外观后第一次切动作（站立→走路） | 要现算整组动画的尺寸和全部贴图，会顿一下（之后有缓存就顺了） |
| 预览刷新有竞态 | 快速连点新建/切皮肤 | 旧图晚到覆盖新图（已加版本号防串台，已修） |

## 二、动画与主窗口

| 问题 | 什么时候发生 | 影响 |
|---|---|---|
| **动作切换判断反了**（最严重） | 角色正在做一次性动作时让它移动 | 指令被丢弃，角色"不听指挥" |
| **托盘隐藏后还在跑** | 关到托盘 | CPU 白烧、幽灵气泡、笔记本风扇转 |
| **气泡漏内存** | 每弹一次气泡 | 内存持续增长，长跑变卡 |
| 离线兜底失效 | WZ 文件读取失败（断线）时 | 角色直接不显示——专门做的兜底功能实际走不到 |
| 帧缓存脏数据 | 缓存重建时 | 可能短暂显示错误的动画帧 |
| 随机发呆动作行为分裂 | 角色发呆时 | 有时走一步就停、有时永远循环、有的动作永远轮不到 |
| 加载宠物失败无提示 | 点了一个加载失败的宠物 | 转圈消失、宠物没换、没有任何提示，还记进"最近使用" |
| 状态聚合器衰减不全 | Agent 干完活 | 有的状态（撒花/等待）永远不回落，桌宠一直"撒花" |

## 三、地图背景

| 问题 | 什么时候发生 | 影响 |
|---|---|---|
| **清理地图贴图缓存时可能崩溃** | 切换地图/停止摄像机模式瞬间 | 正在画图的贴图被并发释放，程序崩溃风险 |
| 地图渲染失败静默 | 地图数据坏了 | 开出一个空白窗口，没有任何提示 |
| 摄像机模式每帧都在分配大块内存 | 摄像机模式运行中 | 每秒约 120MB 内存周转，GC 压力大 |
| 摄像机模式整帧锁住 WZ 数据 | 摄像机模式 + 桌宠同时活动 | 两边互相拖慢 |
| 静态地图的贴图缓存不清 | 模式1 反复切图 | 旧图一直占内存直到挤爆上限 |
| 宠物落地位置可能站屋顶 | 地图有多层平台时 | 宠物站在屋顶/树顶而不是地面 |
| 相机没动时也在重画 | 摄像机模式静止 | 每帧画一张一模一样的图，纯烧 CPU |
| 换 WZ 后地图树不刷新 | 重新配置 WZ | 地图选择器显示旧数据（已确认要修） |
