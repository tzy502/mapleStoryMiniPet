# MiniPet v1.0 — 需求分析

> 阶段：需求分析 · 已完成
> 日期：2026-07-19
> 原则：只说做什么，不说怎么做

---

## 1. 产品定位

桌面悬浮宠物应用。冒险岛风格动画角色，AI 驱动人格和行为。双平台（macOS + Windows）。

## 3. P0 需求详情

### F1 — 桌面悬浮显示

透明无边框窗口，始终置顶，跨桌面跟随，多显示器可用。

### F2 — 素材获取管道

**参考**：
- `mapRederWeb/backend/Program.cs`（R2 wzlib DLL 调用示例）
- `maplestory-wiki-backend/core/wzlib/`（Java 版 wzlib 移植）

直接引用 `WzComparerR2.WzLib` DLL，加载 WZ 文件，产出精灵图条（水平拼接）+ pet_config.json（origin、delay、帧数、帧尺寸）+ 气泡切片 + 纸娃娃部件。导出 PNG+JSON 为纯静态文件，运行时零依赖。

### F3 — 精灵图动画与 Origin 对齐

**参考**：
- `mapRederWeb/frontend/src/index.ts`（PixiJS origin pivot 渲染）
- `MapleSalon2`（纸娃娃合成）

动画顺序：`stand → say → mouse → move → hand → laugh → eye → fly → die`

水平条带按 frameWidth 取帧区域，origin 定位保证动作切换不抖动。60fps，缺失动作 fallback stand。

### F4 — 聊天气泡系统

冒险岛聊天戒指风格九宫格气泡，箭头指向宠物内容顶部，淡入 0.2s → 显示 3~5s → 淡出 0.3s，不阻挡拖拽。

### F5 — 动画行为逻辑

| 触发 | 动画 | 说明 |
|------|------|------|
| 无事件 | stand（循环） | 空闲 |
| 拖拽 | fly（拖拽中） | 结束后回 stand |
| 空闲太久 | 除 stand 外任意（单次） | 播完回 stand |
| 退出 | die（单次），无则直接退 | — |

### F9 — 右键菜单

| 菜单项 | 说明 |
|--------|------|
| 切换人物 | 一级：NPC / MOB / PLAYER → 二级：可用列表 |
| 切换动画 | 可用动作列表 |
| 切换背景 | 地图列表 |
| 切换气泡 | 气泡样式列表 |
| 切换椅子/骑宠 | 仅 PLAYER 时显示 |
| Hermes 终端 | 仅已配置时显示 |
| 设置中心 | 打开 F8 |
| 退出 | die 或直接退出 |

## 4. P1 需求详情

### F6 — 纸娃娃换装系统

**参考**：`MapleSalon2`

换装部位（z-order 分层）：皮肤、发型（前后层）、脸型、帽子、上衣、裤子、鞋子、武器、披风（前后层）、盾牌、手套、耳环。多套预设、坐骑、椅子（与坐骑互斥）、染色。

### F7 — 素材浏览与搜索

三栏布局（分类树 + 列表 + 详情预览），按名称/ID 搜索，按类型筛选，收藏、最近使用。三栏 UI 留到设计阶段确认。

### F8 — 设置面板

**参考**：`prototypes/index.html`

3 主 Tab（桌宠/AI/对话）+ 4 子 Tab（素材/纸娃娃/背景/气泡），修改实时生效。WZ 配置项：wzlib 路径 + BaseWZ 路径。

---

## 5. P2 需求详情

### F10 — 地图背景系统

**参考**：`mapRederWeb/frontend/src/index.ts`

地图 = 地板 + 多个 OBJ。用户可自定义展示已有地图或截取一段。窗口大小固定，不加载整张地图。默认透明。

### F11 — 托盘/状态栏图标

菜单：回归屏幕中心、显示/隐藏、设置中心、退出。

### Hermes AI 集成

- 人格：pet-chat 驱动发言，可切换性格
- 感知：Hermes 状态 → 动画映射（忙/move、出错/hit、完成/skill）
- 对话窗口：纯聊天，不搞复杂 GUI
- 连接状态：查看 WebSocket 连接状态
- 纸娃娃关联：角色随 Hermes 状态联动

## 7. 新增需求 v1.1（2026-08-08）

> 阶段：需求分析 · 逐条确认完成（胶水 2026-08-08 确认 F12/F13/F14）

### F12 — 启动 WZ 加载失败弹窗（P0）

一句话：配置了 WZ 路径但启动读取失败时，弹窗明确提示用户，不再静默。

核心要求：
1. **触发条件**：`wz-config.json` 配置了 `BaseWzPath`（非空），但 `LoadWz` 返回失败（路径无效/文件损坏/异常）
2. **行为**：启动时弹出提示窗，说明 WZ 加载失败原因；桌宠本体继续走缓存启动（不影响使用）
3. **弹窗交互**：可关闭（「知道了」），不阻塞桌宠启动；内容显示失败的具体错误类型（路径无效/文件损坏/未知）
4. **一次软件打开只读取一次**：自动加载只在启动时尝试一次，失败不自动重试
5. **弹窗合并**：与 F14 的读取失败弹窗是同一场景（启动 LoadWz 失败），合并为一次启动只弹一次
6. **弹窗形态**：独立小窗口（居中显示、可点「知道了」关闭），不用悬浮气泡

### F13 — WZ 设置弹窗「刷新当前素材」按钮（P0）

一句话：在 WZ 配置弹窗里加手动刷新按钮，点一次重新读取素材，不用重启软件。

核心要求：
1. **位置**：WZ 配置弹窗（wzlib 路径 / BaseWZ 路径 / 取消 / 保存 那一排）
2. **行为**：点击后按**当前输入框里的路径**（未保存也生效）重新执行 `LoadWz`，成功后刷新素材状态（宠物精灵、地图列表等回到可用状态）
3. **按钮态**：读取中禁用/显示处理中，防止连点并发加载（复用 `_loadLock` 单飞守卫）
4. **结果反馈**：刷新成功/失败在弹窗内明确提示（成功显示素材数量，失败显示原因），与 F12 弹窗同一套错误信息
5. **一次软件打开只读取一次**：指自动加载只一次；刷新按钮是用户手动触发的例外——启动失败后可手动刷新重试，无需重启

### F14 — 默认 wzlib 兜底 + 读取失败引导下载（P0）

一句话：应用自带默认 wzlib，用户配置优先；读取失败时弹窗提示并引导去 GitHub releases 下载。

核心要求：
1. **默认 wzlib**：应用内置（编译期引用的 `WzComparerR2.WzLib.dll` 随应用发布），不依赖用户配置也能启动
2. **用户配置优先**：启动时若配置了 wzlib 路径 → 校验其目录下存在 `WzComparerR2.WzLib.dll`；存在则按用户版本对待，不存在则回退内置并提示「用户配置的 wzlib 无效，已回退默认」
3. **读取失败弹窗**：显示「读取失败」+ 具体原因 + 下载引导：
   - 下载地址：`https://github.com/Kagamia/WzComparerR2/releases`（已验证有效，最新 CI-Build-20260729.1，含 net6/net8 版本 zip）
   - 说明解压后得到 WzComparerR2.WzLib.dll，在弹窗里重新配置路径
   - 做成可点击链接（或复制按钮）
4. **一次软件打开只读取一次**：启动自动加载只一次，失败不自动重试，靠 F13 刷新按钮手动重试

## 8. 新增需求 v1.2 — V0.2.0 音乐模块（2026-08-23）

> 阶段：需求分析 · F15-F17 逐条确认完成（胶水 2026-08-23 确认）
> 范围：V0.2.0 音乐模块（数据一切从 WZ，SSD 客户端 `/Volumes/SSD/mxd/mxd/Data/Sound/` 探针实证：94 个 BgmXX.img 共 1174 首，SoundType=Mp3，`Wz_Sound.ExtractSound()` 可提取）
> 备注：UI 维护/新 UI 迭代需求待设计图出图后追加（F18+）

### F15 — WZ 音乐播放模块（P0）

一句话：桌宠能播放本地 WZ 客户端里的游戏音乐（BGM），像一台迷你点歌机。

核心要求：
1. **音乐来源**：从 WZ 客户端数据读取音乐资源（离线可用，数据一切从 WZ 走）
2. **曲目列表**：能看到全部 BGM 曲目，按 WZ 里的分类浏览（如区域 BGM 库）
3. **播放控制**：播放 / 暂停 / 停止 / 上一首 / 下一首
4. **音量调节**：独立音量控制（不打扰系统其他声音）
5. **播放模式**：单曲循环 / 列表顺序 / 随机播放
6. **当前曲目提示**：播放时桌宠显示当前曲目名（气泡或小提示）
7. **优雅降级**：WZ 未配置 / 音乐数据缺失时，功能不可用但不崩溃、不弹错

### F16 — 音乐播放器界面（P0）

一句话：给音乐模块配一个操作界面，让点歌、控制都顺手。

核心要求：
1. **入口**：设置中心新增「音乐」tab；桌宠右键菜单提供快速入口
2. **曲目浏览**：音乐库列表（WZ 分类 → 曲目），支持搜索曲名
3. **播放控制区**：播放/暂停/上一首/下一首、进度显示、音量滑块、播放模式切换
4. **当前曲目展示**：界面显示正在播放的曲名
5. **与桌宠联动**：播放状态变化时桌宠有反馈（动作/气泡提示曲名）

### F17 — 音乐与场景联动（P1）

一句话：音乐不只是点歌机，还能跟着桌宠的场景/状态走。

核心要求：
1. **地图背景联动**：切换地图背景时，自动播放该地图区域的 BGM（无对应 BGM 就保持当前）
2. **可选开关**：联动功能可开关（默认关或默认开，需求确认时定），纯点歌模式不受影响
3. **状态反馈**：联动触发换歌时，桌宠气泡提示曲名变化

## 9. 新增需求 v1.3 — V0.2.1 无限之路背景（2026-08-27）

> 阶段：需求分析 · F18 逐条确认中（胶水 2026-08-27 口述决策，Agent 整理待复核）
> 背景：V0.2.0 音乐模块已交付（音乐大 tab + BassMusicPlayer + 场景联动 F17）。

### F18 — 无限之路背景（音乐可视化背景，P0）

一句话：播放音乐时，背景显示一条与音乐对应地图风格的、算法随机生成、无限向右延伸的路，停止播放时隐藏。

核心要求：
1. **素材来源**：从「当前音乐对应的地图」加载素材（MapService 现有解析链路，tile + obj + back）。音乐 → 地图的绑定按 F17 已有的 bgm 反查链路（音乐大 tab 播放时已有 mapId）；不重复造轮子
2. **绑定回退链**（胶水口述）：查不到曲子对应地图时 → **沿用上一首的地图素材**；若是第一首（无上一首）或全部未命中 → 从 **射手村 / 废都 / 勇士部落 / 密林 / 林中**（Henesys / Kerning City / Perion / Ellinia / Sleepywood）任选其一作为默认
3. **生成算法硬约束**：地面永远连续、无悬浮断裂。所有地面块取自源地图真实存在的连续路段（「路段切片」方案），只水平平移拼接，不做垂直重组
4. **无限延伸**：背景窗口持续从左向右滚动（**胶水方向：从左走到右**），路无限向前生成、离开视野的路段回收。视野前方预生成，结构上不存在地图尽头
5. **obj 组合**：obj 跟随所属路段切片整体迁移（保留源图中的相对位置），保证背景组合的真实感
6. **第三种背景模式**：与模式1（静态）/ 模式2（摄像机）并列的**模式3「无限之路」**，独立编号，不改动现有两种模式的逻辑
7. **触发/退出**：打开设置中心音乐 tab 并开始播放 → 自动切入模式3；停止播放（Stop，不含暂停）→ 自动隐藏背景窗口并恢复播放前的背景模式。暂停时路保持不动
8. **降级**：源地图解析失败 / 切片池为空 → 模式3 不可用并提示，不影响音乐播放本身；WZ 未加载时同 F15 的降级表现
9. **性能**：滚动渲染复用模式2 摄像机窗口的 30fps DispatcherTimer + WriteableBitmap 直拷方案；切片生成在后台线程，不阻塞 UI
10. **台阶 jump 联动**（胶水 2026-08-27）：地面高度变动 >40px（上台阶/下台阶）→ 人物**强制播 jump 动作**过渡，跳跃期间脚不贴地，落位后恢复贴地；≤40px 小起伏直接贴地不跳
11. **传送门不渲染**：模式3 不渲染 portal（无限之路上传送门无意义）
12. **NPC 随机出现**（胶水新增）：从源图 life 列表抽 NPC（type=n）随机放到生成路的柱上——频率平均每 6~10 根柱 1 个（同屏最多 2~3 个），y 锚定柱表面站地上，播 idle 动作，随柱滚出屏幕消失
13. **怪物随机出现 + 战斗互动**（胶水 2026-08-27 晚补）：
    - 怪物（life type=m）从源图候选，随机出现在路上（与 NPC 同机制，频率另定，同屏上限另定）
    - 怪物随路向人物靠近（视觉=路滚动把怪送到人物面前）
    - **怪物到人物面前（进入攻击判定距离）→ 纸娃娃强制播攻击动作**（探针实证 body 有 swingO1~3/swingT1~3/swingP1~2/stab 系动作）
    - **⚠️ 攻击动作期间武器必须保持渲染不消失**（纸娃娃合成链全程带武器层——有的实现切 attack 时换裸 body 导致武器消失，禁止）
    - 攻击命中 → 怪物播 hit1（受击，探针实证 mob 有 hit1）→ 紧接播 die1（死亡，播完停最后帧）→ 淡出消失，路继续
    - 怪物不主动伤害人物（单向战斗，桌宠无敌）
14. **柱长兜底**：抄来的柱不够到屏幕底 → 用填充块（bsc）垂直续堆到底（bsc 设计上可无限堆叠，接缝无缝）；超出屏幕顶自然裁掉
15. **obj 三分类**：站地 obj（树/路灯/房子）跟柱走 y 锚定柱表面；悬空/天空 obj 不抄（氛围归 back 层）；后景大 obj（远景剪影）归背景带做慢速视差。原则=只有踩在地上的才跟路走
16. **一 BGM 多地图**：反查收全部候选；优先选 town=1 的图（多张随机一张），无 town=1 再随机普通图；**不混池**（多图柱子不混抽，保风格统一；混池留作后续增强）
17. **地图切换淡入淡出**（胶水 2026-08-27）：换歌导致源地图切换时背景 crossfade 过渡（旧路淡出新路淡入，约 0.5s），不瞬切；进入/退出模式3 同样淡入淡出

**待胶水复核的开放点**：
- a) 滚动速度：固定速度（如 60px/s）还是随曲子节奏/类型微调？本需求默认固定常速，可配置
- b) 城镇名→mapId 的默认五图（射手100000000 / 废都103000000 / 勇士102000000 / 密林101000000 / 林中105040300 附近）——**开发前须用探针从 WZ String/EmpireRide 或地图数据实证确切 mapId，禁止拍脑袋**（数据一切从 WZ）
- c) 模式3 与 F17 场景联动的关系：模式3 激活时 F17 的「切图自动换歌」是否互斥（换歌在模式3 下=换素材风格而非换背景）？本需求默认模式3 下 F17 自动暂停响应，切歌只换素材池
