## 二、官方客户端时钟机制（胶水提供，实现参考）

1. **画面**：`AM/PM HH:MM` = 1 个 am|pm + 4 个固定位置数字 + 1 个 comma；位置固定不跳动；按素材 origin 对齐
2. **时间源**：创建时服务器给初始时分秒；之后本地每秒计时器推进（60s→1min，24h→回零），秒只控制 comma 闪烁（偶显奇隐）
3. **显示**：内部 24h 制，显示转 12h 制带 AM/PM（0~11=AM，12~23=PM，13-23 显示减 12，两位补零；午夜 0 点显示 AM 00:xx——官方就这样，复刻保持）
4. **位置**：地图 clock 配置 x,y + 固定偏移 (+18,+83)；属地图场景层（跟镜头走），浮动层高于普通地图内容
5. **生命周期**：随地图清理；重复通知会叠多个时钟（官方 bug，桌宠实现要去重）

## 四、实现注意（给未来提示语）

- 素材 origin 全是 (0,0)（fontTime 系实测）——对齐按固定像素位排版即可
- 数字 26×35 / comma 17×35：HH:MM 总宽 ≈ 22(am)+4×26+17 ≈ 143px + 间距
- 一次性预载进 SpriteService 缓存；换数字只换 DrawBitmap 源
- 桌宠时钟为屏幕元素时不受地图镜头影响（与官方地图时钟的区别）
